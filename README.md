## Short Description
My Movies Website is a simple web application developed using PHP, MySQL, HTML, and CSS.  
The website allows users to register, log in, and view movie-related pages.  
It demonstrates form handling, database connectivity, and basic user authentication.

## 💻 Required Environment
- XAMPP
- Apache Server
- MySQL
- PHP
- phpMyAdmin
- Web Browser (Chrome, Edge, or Firefox)
